📁 README.txt — Assignment Guide
This assignment is based on a Banking system where one can create a bank account with a password for security,view their account,deposit and withdraw money, update account holder's name, see the list of all accounts and also delete their accounts if needed.

To compile and run this program on Linux,
1. Open terminal.
2. Give command using "cd" and the directory of the cpp file on your computer.
3. Then "g++ banking_system.cpp".
4. Then "./a.out".
5. After compiling and running the code successfully, choose the options according to your wish from the screen and check it.

You can also compile and run this program on different IDE. I used Linux system. That's why, I particularly mentioned it.
